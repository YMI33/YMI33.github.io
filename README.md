## 研究内容简介
我的研究主要围绕地形的气候效应与古气候过程，重点包括：
- 大型冰盖的气候效应与反馈机制
- 冰盖数值模式及地球系统模式开发
- 第四纪古气候数值模拟（GREB-ISM）
- Wasserstein 距离在气候科学中的应用
- 先进数学方法在气候科学的应用
- 大地形对行星及地球气候的影响
